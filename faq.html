一般

Bob は AI を活用したコーディングアシスタントです。コードの作成・リファクタリング・各種タスクの実行をサポートします。カスタムモードや指示によって機能を拡張することもできます。

Bob は大規模言語モデル（LLM）を使ってリクエストを理解し、アクションに変換します。主な機能は次のとおりです：

  • プロジェクト内のファイルの読み書き
  • ターミナルでのコマンド実行
  • インターネットの閲覧（有効化時）
  • MCP（Model Context Protocol）を通じた外部ツールの利用

チャットインターフェースから指示を入力し、Bob が提案するアクションを確認・承認して操作します。

Bob はさまざまなコーディングタスクを支援します：

  • 自然言語の説明からコードを生成する
  • 既存コードのリファクタリング
  • バグ修正
  • ドキュメントの作成
  • コードの説明
  • コードベースへの質問への回答
  • 繰り返し作業の自動化
  • 新しいファイルやプロジェクトの作成

以下のデータ種別は Bob で処理しないでください：

  • SPI（機密個人情報）
  • PHI（個人医療情報）
  • 輸出規制対象データ（ITAR、APP など）
  • 規制対象の金融データ（銀行口座番号、PAN、非公開財務情報など）

Bob は強力なツールです。責任を持って使用してください：

  • Bob はミスをする場合があります。 承認する前に必ず変更内容を確認してください。
  • Bob はコマンドを実行できます。 自動承認を使用している場合は特に注意が必要です。

使い方

Bob パネルを開き、チャットボックスにタスクを入力してください。何をしたいかを明確・具体的に記述すると、より正確な結果が得られます。

チャット入力欄のドロップダウンメニューから別のモードを選択するか、/ コマンドを使って特定のモードに切り替えることができます。

ツールは Bob がシステムと対話するための仕組みです。Bob はタスクに応じて適切なツールを自動的に選択・使用します。ユーザーが直接ツールを呼び出す必要はありません。各ツール使用時に承認または拒否のプロンプトが表示されます。

コンテキストメンションは、ファイル・フォルダ・問題など、プロジェクトの特定の情報を Bob に伝える方法です。@ 記号の後にアイテムを指定します（例：@/src/file.ts、@problems）。

はい、Bob はコマンドを実行できます。コマンドの自動承認を有効にしていない限り、実行前に承認プロンプトが表示されます。コマンドの自動承認には十分注意してください。

Bob が提案するアクションを承認または拒否することでフィードバックできます。フィードバックフィールドを使って追加のコメントを送ることもできます。

はい、いくつかの方法でカスタマイズできます：

  • カスタム指示： すべてのモードに適用される全般的な指示や、モード固有の指示を設定できます。
  • カスタムモード： 独自のプロンプトとツール権限を持つモードを作成できます。
  • Bob ルール： プロジェクトルートの .bob/rules/ フォルダにマークダウンのルールファイルを作成して追加ガイドラインを提供できます。
  • 設定： 自動承認・差分編集などの各種設定を調整できます。

はい、Bob にはアクションを自動的に承認するいくつかの設定があります。有効にすると、確認プロンプトなしでアクションが実行されます。

高度な機能

MCP は Bob が外部サーバーと通信するためのプロトコルです。カスタムツールやリソースを追加することで Bob の機能を拡張できます。

はい、独自の MCP サーバーを作成して Bob にカスタム機能を追加することができます。

トラブルシューティング

以下をご確認ください：

  • API キーが正しく、有効期限が切れていないか確認する
  • インターネット接続を確認する
  • VS Code を再起動する

Bob は VS Code 組み込みのファイル編集機能を使用しています。標準の「元に戻す」コマンド（Ctrl + Z / Cmd + Z）で変更を元に戻すことができます。また、チェックポイント機能を使ってファイルへの変更を特定時点まで戻すことも可能です。
